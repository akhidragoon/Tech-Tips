Back Up Your Dotfiles with Git

◷ April 6, 2026● Kernel & Craft◉ 6 min read

Dotfiles (dotfiles) are those hidden configuration files in your home directory that customize your development environment. From .bashrc and .vimrc to .config/ settings, these files define your personalized workspace. Losing access to these configurations can be devastating, but backing them up with Git is a simple, robust solution that ensures you always have access to your perfect setup.

Essential Dotfiles to Back Up


.bashrc / .zshrc - Shell configuration for bash or zsh
⌗
.bash_profile - Shell profile executed for login shells
◎
.vimrc / .config/nvim/init.vim - Editor configuration
✈
.gitignore - Prevents accidental commits of unwanted files
□
.screenrc / .tmux.conf - Terminal multiplexer settings

Personal configs in ~/.config - GUI application settings (wezterm, vscode, etc.)

Step-by-Step Setup

◷ Create Your Dotfiles Repository

# Create a new repository (do this on your local machine) mkdir ~/projects/dotfiles cd ~/projects/dotfiles git init git add ~/.bashrc ~/.zshrc ~/.bash_profile 2>/dev/null git add ~/.vimrc ~/.config/nvim/init.vim 2>/dev/null git add ~/.config/wezterm 2>/dev/null git add ~/.config/Code/User/settings.json 2>/dev/null git add ~/.screenrc ~/.tmux.conf 2>/dev/null git add .gitignore 2>/dev/null git commit -m "Initial dotfiles backup" # Back up existing configs cp -a ~/.bashrc ~/projects/dotfiles/ cp -a ~/.zshrc ~/projects/dotfiles/ 2>/dev/null cp -a ~/.bash_profile ~/projects/dotfiles/ 2>/dev/null # Create symlinks for active use ln -sf ~/projects/dotfiles/.bashrc ~/.bashrc ln -sf ~/projects/dotfiles/.zshrc ~/.zshrc 2>/dev/null ln -sf ~/projects/dotfiles/.bash_profile ~/.bash_profile # Add symlink management to your shell init (optional but recommended) cat >> ~/.bashrc << 'EOF' # Auto-update dotfiles symlinks if [ -d "$HOME/projects/dotfiles" ]; then for file in "$HOME/projects/dotfiles"/.*; do filename=$(basename "$file") if [ -f "$file" ] && [ ! -L "~$filename" ]; then ln -sf "$file" "~$filename" fi done fi EOF

Advanced Configuration

Git Configuration for Dotfiles

# Configure git for dotfiles repository git config user.name "Your Name" git config user.email "your.email@example.com" # Create a separate git user for public dotfiles (optional) git config user.name "Your Public Dotfiles" git config user.email "public@dotfiles.example.com" git config --global credential.helper "store"

Structured Dotfiles Repository

# Create a well-organized structure mkdir -p config/shell mkdir -p config/editor mkdir -p config/gui mkdir -p scripts # Move files to organized structure cp ~/.bashrc config/shell/bashrc cp ~/.vimrc config/editor/vimrc cp ~/.zshrc config/shell/zshrc 2>/dev/null # Create a README for future maintenance cat > README.md << 'EOF' # My Dotfiles This repository contains configuration files for my development environment. ## Usage These files are symlinked to your home directory. To switch between different configurations, replace the symlinks. ## Files - `config/shell/` - Shell configurations (.bashrc, .zshrc, etc.) - `config/editor/` - Editor configurations (.vimrc, .config/nvim/init.vim, etc.) - `config/gui/` - GUI application settings - `scripts/` - Utility scripts for dotfile management EOF

Automation Scripts

Update Script

#!/bin/bash # update-dotfiles.sh - Keep your home directory symlinked to dotfiles repo REPO_PATH="$HOME/projects/dotfiles" BACKUP_DIR="$HOME/dotfiles_backup" timestamp=$(date +%Y%m%d_%H%M%S) mkdir -p "$BACKUP_DIR/$timestamp" # Backup current dotfiles (excluding symlinks) echo "Creating backup of current dotfiles..." for file in ~/.bashrc ~/.zshrc ~/.bash_profile ~/.vimrc ~/.screenrc ~/.tmux.conf; do if [ -L "$file" ]; then # It's a symlink, skip continue fi cp -a "$file" "$BACKUP_DIR/$timestamp/" done # Update symlinks echo "Updating symlinks..." for file in "$REPO_PATH"/.*; do filename=$(basename "$file") if [ -f "$file" ] && [ ! -L "~$filename" ]; then ln -sf "$file" "~$filename" echo "Symlinked ~$filename" fi done echo "Dotfiles updated successfully!" echo "Backup available in: $BACKUP_DIR/$timestamp"

Commit Template

#!/bin/bash # commit-dotfiles.sh - Commit changes with proper formatting # Add all changed files for file in ~/.bashrc ~/.zshrc ~/.bash_profile ~/.vimrc ~/.screenrc ~/.tmux.conf; do if [ -e "~/projects/dotfiles/$(basename "$file")" ]; then git add "~/projects/dotfiles/$(basename "$file")" fi done # Create commit message with timestamp git add -A timestamp=$(date '+%Y-%m-%d %H:%M:%S') git commit -m "Update dotfiles - $timestamp" \ -m "Changes to shell, editor, and terminal configurations" # Push to remote (if configured) git push origin main

Directory Structure Example


config/shell/.bashrc - Bash shell configuration
⌗
config/shell/.zshrc - Zsh shell configuration (if using zsh)
◎
config/editor/.vimrc - Vim editor configuration
◎
config/editor/init.vim - Neovim configuration

config/gui/wezterm.lua - Terminal theme and settings

config/gui/settings.json - VS Code or other IDE settings

Security and Best Practices

Exclude Sensitive Data

Never commit passwords, API keys, or other sensitive information. Use a comprehensive .gitignore:

# Example .gitignore for dotfiles # Ignore IDE files .vscode/ .idea/ # Ignore OS files .DS_Store Thumbs.db # Ignore temporary files *.swp *.swo *~ # Ignore logs *.log # Ignore backups *backup* *~

Version Control Benefits

  • Cross-machine portability - Your setup follows you from machine to machine
  • Version history - See changes to your configuration over time
  • Easy recovery - Quick restoration after system crashes or reinstallation
  • Collaboration - Share your perfect setup with others
  • Experimentation - Try new configurations without fear - just git reset

Final Steps

  1. Choose your setup method - Start with basic files, then add more as needed
  2. Test thoroughly - Ensure your shell still works and editors function correctly
  3. Create automation - Set up scripts to maintain your dotfiles easily
  4. Document your changes - Write README or commit messages explaining configurations
  5. Regular backups - Update your dotfiles repository periodically

Backing up your dotfiles with Git is one of the most valuable investments you can make in your Linux workflow. It transforms hours of reconfiguration pain into a simple git checkout command, ensuring your development environment is always ready when you are.

Getting Started

Start with just your shell configuration (.bashrc) and build from there. The key is consistency - even backing up a few key files immediately gives you a safety net for the future.
